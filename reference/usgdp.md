# Quarterly US GDP

Quarterly US GDP, 1947:1 - 2006:1.

## Usage

``` r
usgdp
```

## Format

Quarterly time series of length 237.

## Source

Hyndman, R.J., Koehler, A.B., Ord, J.K., and Snyder, R.D. (2008)
*Forecasting with exponential smoothing: the state space approach*,
Springer.
[doi:10.1007/978-3-540-71918-2](https://doi.org/10.1007/978-3-540-71918-2)
.

## References

<https://robjhyndman.com/expsmooth/>

## Examples

``` r

plot(usgdp, main = "Quarterly US GDP", xlab = "Year", ylab = "US Dollars")

```
